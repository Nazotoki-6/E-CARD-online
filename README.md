## ゲーム仕様

- 対戦開始時に「皇帝側 / 奴隷側」を **50%ずつランダム抽選**
- 抽選カードが回転し、結果を表示してから第1戦へ移行
- 全12試合のシリーズ戦
- 3試合ごとに「皇帝側 / 奴隷側」を自動交代
- 各試合は「特殊カード1枚 + 市民4枚」で開始
- 市民同士は引き分けとなり、使用したカードを捨てて続行
- **各試合の1・3手目は皇帝側が先出し、2・4手目は奴隷側が先出し**
- 4手連続で市民同士なら、残りが「皇帝 vs 奴隷」になるため**奴隷側の勝利を自動確定**
- そのため1試合の決着判定は最大4手
- 最強CPU v2（最適混合 + 残り手札・役割・先手後手・過去/直近傾向の学習）
- CPUの手はプレイヤーが選ぶ前に内部確定。後出しなし
- BGM：`audio/Devil_Disaster.mp3`（ループ再生）／効果音：Web Audio API
- 「3 → 2 → 1 → OPEN」から2枚を同時公開
- 12戦マッチ / 個別試合 / 皇帝側 / 奴隷側 / 連勝記録をブラウザ内へ保存
- 途中の12戦マッチを自動保存して再開可能
- PWA・完全オフライン対応

## v18.5 CPU戦型システム

- 12戦シリーズ開始時にCPUが内部で「慎重型 / 攻撃型 / 撹乱型」のいずれかをランダム選択
- 戦型は対戦中は非公開で、12戦終了後に今回のCPU PROFILEとして表示
- 慎重型: 均衡寄りで読みを過信せず、特殊カードをやや温存
- 攻撃型: プレイヤーの癖を強めに利用し、好機では特殊カードをやや早めに使用
- 撹乱型: 均衡を軸に小さな確率揺らぎを混ぜ、タイミングを固定しにくくする
- どの戦型も最適混合を土台にしているため、性格差で極端に弱くならないよう調整
- CPUカードはこれまで通りプレイヤー選択前に確定し、後出しはしない
- オートセーブ/再開時にも同じCPU戦型を維持
