# E-CARD ONLINE v9 — START SIDE LOTTERY

皇帝・市民・奴隷の3種類のカードを使い、最強CPUと戦うスマートフォン向け心理戦ブラウザゲームです。GitHub Pagesへそのまま公開できます。

`皇帝・市民・奴隷の3種類のカードで最強CPUと戦う心理戦ブラウザゲーム。開始陣営50%抽選・12戦マッチ・BGM/効果音・戦績保存・PWA/オフライン対応。`

## ゲーム仕様

- 対戦開始時に「皇帝側 / 奴隷側」を **50%ずつランダム抽選**
- 抽選カードが回転し、結果を表示してから第1戦へ移行
- 全12試合のシリーズ戦
- 3試合ごとに「皇帝側 / 奴隷側」を自動交代
- 各試合は「特殊カード1枚 + 市民4枚」で開始
- 市民同士は引き分けとなり、使用したカードを捨てて続行
- **各試合の1・3手目は皇帝側が先出し、2・4手目は奴隷側が先出し**
- 4手連続で市民同士なら、残りが「皇帝 vs 奴隷」になるため**奴隷側の勝利を自動確定**
- そのため1試合の決着判定は最大4手
- 最強CPU v2（最適混合 + 残り手札・役割・先手後手・過去/直近傾向の学習）
- CPUの手はプレイヤーが選ぶ前に内部確定。後出しなし
- オリジナルBGM・効果音
- 「3 → 2 → 1 → OPEN」から2枚を同時公開
- 12戦マッチ / 個別試合 / 皇帝側 / 奴隷側 / 連勝記録をブラウザ内へ保存
- 途中の12戦マッチを自動保存して再開可能
- PWA・完全オフライン対応

## v9 で追加した開始陣営抽選

- タイトル画面から任意に皇帝側・奴隷側を選ぶ方式を廃止
- 「陣営を抽選する」ボタンで開始陣営を50% / 50%で決定
- Web Crypto APIが使える環境では乱数抽選に利用し、非対応時のみ通常乱数へフォールバック
- カード回転・抽選音・振動・結果表示の演出を追加
- 抽選結果が皇帝側なら「皇帝 → 奴隷 → 皇帝 → 奴隷」、奴隷側ならその逆で3試合ごとに交代
- 12戦終了後の「もう一度」は同じ陣営固定ではなく、タイトルへ戻って再抽選
- 途中保存がある状態で新規抽選するときは確認を表示

## GitHub Pagesへの公開

このフォルダの**中身をすべて**リポジトリ直下へアップロードしてください。

必要ファイル：

- `index.html`
- `style.css`
- `script.js`
- `manifest.json`
- `service-worker.js`
- `images/`
- `icons/`

GitHubで `Settings → Pages → Deploy from a branch → main / root` を選択します。

公開後、最初にオンライン状態で1回ページを開いてください。Service Workerが必要ファイルを保存し、その後は機内モードなどでも起動できます。

## 更新時の注意

GitHubへ新しい版をアップロードするときは、ブラウザが古いファイルを使い続けないよう `service-worker.js` の `CACHE_NAME` を変更してください。

現在：`ecard-online-v9-20260920`

## v12 位置バレ対策

- 皇帝／奴隷のカード位置は試合開始時にランダム化
- 市民同士の引き分け後は、残った手札を毎回再シャッフル
- プレイヤー側とCPU側はそれぞれ独立にシャッフル
- シャッフルは可能な場合 `crypto.getRandomValues()` を使用
- 将来の2人オンライン対戦では、各スマホが自分の手札表示だけを独立シャッフルする設計に流用可能
- 選択中のカードは確定するまで位置を固定し、選んでいる途中でカードが入れ替わることはありません
